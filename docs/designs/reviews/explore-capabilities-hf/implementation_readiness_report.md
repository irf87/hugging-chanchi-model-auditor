## Requested checks

All three reviewers checked these points.

* **Removed concepts:** none remain in the plan. There is no `share`, no `hint_commands`, no `explore_signal_stale` and no `now` parameter. "now at migration 003" (line 1117) and `utc_now()` (line 1053) are ordinary uses.
* **Phase 1 sort:** items 2 and 3 state it as deprioritized last, `cost_tier` lowest first, `n_task_type` highest first, then `spec`. This matches the Technical Plan.
* **`deprioritized` values:** the plan uses `null | "weak_start" | "red_flag_low_data"`, and `red_flag_low_data` wins when both apply (tested at line 971). This matches.
* **Fetch script and the database:** the plan never has the script access the database. The wording "reads only the map and the Hub" is inaccurate, because the script also reads the previous snapshot (N6).
* **Code claims confirmed:**
  * 003 is the next free migration number.
  * `uv run chanchi db migrate --template` regenerates `template.db` (cli.py:69, db.py:146).
  * The backup name `chanchi.db.bak-v2` is correct.
  * `pyproject.toml` needs no change, because Hatchling ships every non-ignored file under `src/chanchi`.
  * `.claude/worktrees/` is gitignored.
  * `subprocess` appears only in `projects.py`.
  * `set_model` rejects a spec with an effort and rejects `human:human`.
  * `--tags` replaces the whole tag list.

## Author decision

Accepted on 2026-11-18, all findings, with these choices:

* B1: a real Hub response for `zai-org/GLM-5.3` (fetched without a token on 2026-11-18) is in the Technical Plan with a field mapping. The fetch showed three facts the plan lacked: dates come in two formats, broken files come back as `{"filename", "error"}` with no `data`, and a missing repo answers 401 without a token. Rows from open pull requests (`pullRequest`), including GLM-5.2's terminal-bench-2.1 rows, count like the others but are marked `pull_request: true`; a Risks row covers them.
* M1: `capabilities` is a flat string (`"vision=yes"`), so `render.py` keeps the models table.
* M12: `hfsignals.SNAPSHOT_PATH` plus an autouse fixture in `tests/conftest.py`.
* M17: the "prefer an `explore` spec when the budget allows" rule is added to the Technical Plan's skill list.
* M22: owner step 1 checks or registers `agy:gemini-4-hydrogen-high` before S1.

The Detailed Implementation Plan was rewritten (36 numbered files) and 14 Technical Plan edits applied.
